01Domain-Aware Compression

Coding gets its own
compression strategy.

Generic summarizers treat code like prose. They compress indiscriminately — and lose the exact stack frame that caused the error, or the function signature that was changed three turns ago.

Prexi's T5 model uses a coding-specific compression strategy: stack traces and error messages compress aggressively (they're noisy). Live code blocks, file names, and unresolved errors are preserved verbatim.

Compresses hard

Resolved error messages · Successful run logs · "Let me try..." attempts · Repeated explanations · Dead-end branches

Preserved verbatim

Active code blocks · Unresolved errors · File paths · Function signatures · The current task goal

02MCP Integration

Works inside Cursor, Windsurf, Claude Desktop.

The Prexi MCP server exposes 4 tools your AI IDE can call directly. No proxy layer needed.

compress

Compress the current conversation history. Returns compressed messages + tokens saved + domain classification.

classify

Classify the conversation domain and intent. Returns domain, risk level, emotional state, intent.

remember

Store a key fact or decision for this session. Persists across context window resets.

recall

Retrieve stored facts by keyword. Use at the start of a new session to restore context.

Cursor — mcp.json
{
  "mcpServers": {
    "Prexi": {
      "command": "npx",
      "args": ["-y", "@echoregent/mcp-server"],
      "env": { "ECHOREGENT_KEY": "your-key" }
    }
  }
}
