01The Problem

Context debt is the silent agent killer.

A research agent that runs 200 turns sends the full trajectory to the LLM at turn 200. Most of that trajectory is completed sub-tasks, failed attempts, and intermediate reasoning that's no longer relevant.

The model's attention dilutes across the noise. It starts repeating itself, losing track of the goal, or hitting the context limit and crashing mid-run.

And you pay for every token in that bloated trajectory — every turn, every call.

Without Prexi

Token cost grows linearly with agent turns. A 200-turn run costs 200x more than turn 1. Attention degrades. Context limits crash long runs.

with Prexi

Completed sub-tasks compress. Active goals stay intact. Context window stays bounded. The agent runs indefinitely on a predictable per-turn cost.

02Architecture

Drop in before the LLM call. Nothing else changes.

Intent tracking

DistilBERT classifies each turn's intent, domain, and risk. The compressor uses this to decide what's safe to summarise vs. what must be preserved verbatim.

Trajectory compression

Completed tool calls, resolved sub-tasks, and dead-end branches compress aggressively. Active goals, current state, and unresolved errors are kept in full.

Session memory

Use the remember and recall MCP tools to store key facts outside the context window entirely. The agent retrieves them on demand — zero tokens until needed.

04Privacy

Agent trajectories never leave the pipeline.

No message storage

Agent trajectories are processed in memory. Nothing is stored after compression completes. No logs of message content, no buffers, no training data collection.

Response header proof

Every call returns x-echoregent-tokens-saved, x-echoregent-domain, and x-echoregent-protected so you can verify behaviour at the application level.
